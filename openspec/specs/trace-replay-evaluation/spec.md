# trace-replay-evaluation Specification

## Purpose

让维护者用可复用的合成轨迹检验 Agent 在模型输出、工具派发和任务状态之间的执行规则，并在相同用例条件下定位程序版本间的行为差异。

## Requirements

### Requirement: 回放用例集具有固定身份

回放入口 SHALL 在运行前验证版本化合成用例集，并从用于执行的同一份输入字节计算 SHA-256。每个用例 SHALL 定义唯一标识、角色、运行选项、按顺序排列的事件和预期断言。

#### Scenario: 固定用例和预期结果

- **GIVEN** 包含模型响应、模拟 MCP 事件及断言的有效合成用例集
- **WHEN** 维护者执行回放
- **THEN** 报告标明用例集 SHA-256、计划用例 ID 和实际运行源码身份

#### Scenario: 用例集无法验证

- **WHEN** 用例集版本不受支持、用例 ID 重复或必需事件字段缺失
- **THEN** 入口在运行用例前返回输入错误

### Requirement: 回放在隔离环境按事件对齐

每个用例 SHALL 使用新建的隔离状态和固定的模拟模型、MCP 响应执行。发出模型请求或工具调用时，回放入口 SHALL 先校验该请求是否匹配下一预期事件，再提供对应响应。

#### Scenario: 在禁网环境执行

- **WHEN** 在禁网 Docker 中执行合成用例集
- **THEN** 每个用例使用独立的临时任务与账本，执行链路使用模拟响应，外部模型及 MCP 调用均为零

#### Scenario: 轨迹与当前执行发生分歧

- **WHEN** 执行链路请求了未预期的模型请求用途、工具或工具参数，或者在尚有必需事件时提前结束
- **THEN** 回放停止当前用例，记录首个差异的步骤、阶段及原因，并将用例记为失败
- **AND** 只有请求与预期事件匹配时才供应对应回执

### Requirement: 回放用例验证工具派发和完成核验

内置用例集 SHALL 对实际工具派发事件、写入效果状态和完成声明执行可判定的断言。

#### Scenario: 输出截断携带工具调用

- **GIVEN** 启用该用例的有界恢复选项，且模拟提供方返回可结算但携带工具调用的截断响应
- **WHEN** 执行链路处理该响应并请求重新生成
- **THEN** 截断批次的工具派发次数为零，重新生成基于最后完整的历史，并保留该次截断响应的结算记录

#### Scenario: 写入超时且效果未知

- **GIVEN** 一个符合写入前置条件的工具调用到达模拟 MCP 服务
- **WHEN** 该服务在返回写入结果前超时，后续模型响应再次提出写入
- **THEN** 首次写入效果记录为未知，第二次写入未到达模拟服务，运行未接受完成声明

#### Scenario: 缺少写后回查时提出完成声明

- **GIVEN** 用例已执行必要操作并成功写入目标案件
- **WHEN** 模型在读回该次写入后的业务状态之前提出完成声明
- **THEN** 执行链路以缺少写后回查为由拒绝声明，报告观测到零次接受的完成声明

#### Scenario: 有效写后回查后提出完成声明

- **GIVEN** 用例已执行必要操作并成功写入目标案件
- **WHEN** 模型通过同一案件的后续读取获得所需终态，再提出完成声明
- **THEN** 执行链路接受该声明，报告记录预期的写入次数、读回和完成事件

### Requirement: 报告按用例呈现结果与首个差异

回放报告 SHALL 记录合成证据类型、用例集、源码与评测器身份，以及每个计划用例的结果和观察到的断言值。结果与汇总 SHALL 覆盖通过、失败和未执行，诊断仅包含可比较的事件摘要与安全错误信息。

#### Scenario: 断言失败或用例未执行

- **WHEN** 实际派发、状态或完成事件与断言不符，或某个计划用例未执行
- **THEN** 报告保留该用例及原因，将其纳入计划数并返回失败状态
- **AND** 对断言不符的用例输出首个失败断言的预期值和观测值

#### Scenario: 输出目录已存在

- **WHEN** 指定的输出目录已存在
- **THEN** 入口在运行用例前返回输入错误，已有报告与日志字节保持原样

### Requirement: 对照报告保持回放条件一致

对照入口 SHALL 校验两份报告的版本、用例集 SHA-256、有序用例清单、评测器身份和已记录的运行环境版本，再比较各用例的结果和事件摘要。

#### Scenario: 兼容报告的行为发生变化

- **WHEN** 两份兼容报告中，同一用例的执行事件或断言结果发生变化
- **THEN** 对照报告指明用例、首个差异步骤或断言，并给出两侧结果及源码身份

#### Scenario: 回放条件不同

- **WHEN** 两份报告的用例集 SHA-256、用例清单、评测器身份或已记录的运行环境版本不同
- **THEN** 对照入口返回不可比较的原因
