# F7：实验清单、检查适用性与结果汇总

建立：2026-11-01。基于已合并的 F0–F6（main `4ade699`）。本变更只做实验工具与合成数据验证，不启动真实模型、真实任务、官方判分或临床评审。状态与权限只查 [REVIEW_STATE](../../../reviews/REVIEW_STATE.md)。

## 为什么需要

Z4/Z5 的实验如果没有先冻结清单，很容易出现：

- 先跑再选题、看过结果再换题；
- 只统计成功记录，失败/跳过/未运行不进分母；
- 把不同候选、模型或模拟器条件混在一起比较；
- 缺日志、缺用量时用 0 或“通过”补齐；
- 把多项机制一起改后的结果说成单项收益。

F7 提供独立于被测 Agent 的 manifest 与汇总工具，让实验条件、检查适用性和分母在运行前固定，运行后只按事实计数。

## 范围

- `experiment_manifest.py`：`chi-experiment-campaign-v1` 的严格校验、off/on 对照约束、freeze SHA、CLI。
- `experiment_summary.py`：`chi-experiment-record-v1` 的汇总，全分母、缺证据/缺用量/跳过/阻断、候选一致性、官方分数只保留不合成，CLI。
- 合成记录测试；不调用真实模型。
- 为 Z4 单变量对照、Z5 九题未见集提供清单和汇总入口；具体任务/次数仍需用户批准。

## 非范围

- 不执行实验、不创建世界、不读取真实轨迹或隐藏材料。
- 不计算“成功率”、不生成官方 reward、不做临床 verdict。
- 不引入数据库/可视化平台；JSON + CLI 足够当前规模。
- 不替代 Z4/Z5 的任务选择与用户授权。
