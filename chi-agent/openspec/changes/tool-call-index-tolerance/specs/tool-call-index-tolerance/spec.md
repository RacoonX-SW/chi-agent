# 工具调用索引兼容契约

本契约只覆盖 `ToolContract` 对 assistant tool_call 的校验与历史回放；不改变工具定义、阶段可见性或真实运行授权。

## 需求：可选的调用位置索引不应终止整轮

### 场景：响应带位置索引

给定 OpenAI 兼容响应中的 tool_call 含 `index`（非负整数）、合法 `id`/`type`/`function` 和合法参数，校验应接受该批次并记录调用；存储的批次消息不得包含 `index`。

### 场景：历史回放带或不带位置索引

给定已记录的批次，后续请求历史中的 assistant 消息无论是否包含同一个 `index`，只要其他字段逐项一致，都应通过历史校验。

### 场景：非法索引

`index` 为负数、字符串、浮点、布尔或 `null` 时，批次判为 `tool_batch_invalid`，且不提交任何调用记录、不占用调用 id。

## 需求：其余严格性保持不变

### 场景：未知字段

tool_call 出现 `id`/`type`/`function`/`index` 之外的键时，批次判为 `tool_batch_invalid`，不落盘。

### 场景：既有校验不变

重复 id、未知工具名、参数不是 JSON、参数不符合 schema、结果未回放、历史中伪造 tool 结果、预算反馈过期等既有失败路径保持原错误码与原子性。
